PromptPay QR JavaScript demo

Generate browser-safe PromptPay payloads with promptpay-generator-js, then render them to Canvas with qrcode. No QR renderer is included in the core library.

Static QR

Valid use cases

Static QR codes omit field 54. Dynamic QR codes include a fixed, two-decimal amount.

Validation use cases

Invalid input produces a clear error and hides the previous QR so stale payment data cannot be scanned.

Integration examples

Build this checkout with npm run build before using the local bundle examples below.

ES modules (local build)

import QRCode from 'qrcode';
import { generatePayload } from './dist/index.js';

// Static: payer enters the amount in their banking app.
const staticPayload = generatePayload('089-999-9999');

// Dynamic: amount is fixed. Numbers and decimal strings are supported.
const dynamicPayload = generatePayload('1234567890123', 420);
const exactDecimal = generatePayload('004999000288505', '100.25');

await QRCode.toCanvas(document.querySelector('#qr'), dynamicPayload);

Direct browser (local build + QR renderer CDN)

<canvas id="qr"></canvas>
<script type="module">
  import QRCode from 'https://cdn.jsdelivr.net/npm/qrcode/+esm';
  import { generatePayload } from './dist/index.js';

  const payload = generatePayload('089-999-9999', '420');
  await QRCode.toCanvas(document.querySelector('#qr'), payload);
</script>
